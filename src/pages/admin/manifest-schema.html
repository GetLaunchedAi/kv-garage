Product Manifest CSV Format

This document describes the required format for CSV manifest files used to upload product data for packs.

📥 Download CSV Template 📋 View JSON Schema

Required Fields

Field Name Type Description Example Aliases
sku string Stock Keeping Unit - Unique identifier for the product CASE-001 -
item_name string Name of the product/item iPhone 12/13 Clear Case product_name, name, product
quantity integer Number of units available 25 qty, qnty, amount
estimated_value float Estimated resale value per unit in USD 12.00 value, est_value, est_val, price, est

Optional Fields

Field Name Type Description Default Example
product_name string Product name (alias for item_name) - iPhone 12/13 Clear Case
condition string Condition of the product new new
condition_grade string Grade of condition (e.g., excellent, good, fair) - new
category string Product category Misc Phone Cases
brand string Brand name of the product Generic Generic
notes string Additional notes or description about the product "" "Clear protective case, various colors"

CSV Format Specifications

  • Delimiter: Comma (,)
  • Enclosure: Double quotes (")
  • Encoding: UTF-8
  • Header Row: Required (first row must contain field names)
  • Fields with commas: Must be enclosed in double quotes

Example CSV

sku,item_name,product_name,quantity,condition,condition_grade,estimated_value,category,brand,notes
CASE-001,iPhone 12/13 Clear Case,iPhone 12/13 Clear Case,25,new,new,12.00,Phone Cases,Generic,"Clear protective case, various colors"
CBL-001,Lightning Cable 6ft,Lightning Cable 6ft,40,new,new,15.00,Cables,Generic,"MFi certified, braided cable"
PROT-001,iPhone 12/13 Screen Protector,iPhone 12/13 Screen Protector,30,new,new,8.00,Screen Protectors,Generic,"Tempered glass, 9H hardness"

Validation Rules

  • sku: Required, must be unique within the manifest
  • item_name: Required, string
  • quantity: Required, must be a positive integer
  • estimated_value: Required, must be a positive number (float)
  • condition: Optional, defaults to "new" if not provided
  • category: Optional, defaults to "Misc" if not provided
  • brand: Optional, defaults to "Generic" if not provided
  • notes: Optional, can contain commas (will be quoted in CSV)

Field Aliases

The system accepts alternative field names (aliases) for convenience:

  • item_name can also be: product_name, name, product
  • quantity can also be: qty, qnty, amount
  • estimated_value can also be: value, est_value, est_val, price, est

💡 Tips

  • Use the downloadable template to ensure correct formatting
  • Fields containing commas must be enclosed in double quotes
  • All numeric fields (quantity, estimated_value) should not include currency symbols
  • The CSV file must have a header row with field names
  • Empty rows will be ignored during processing
